# Decoding the Blue Monday Colour Code

## Background

To understand how to decode the colour keys on New Order's *Blue Monday* sleeve, we first need to look at the original 12-inch single.

The sleeve was designed as a die-cut replica of a 5¼-inch floppy disk. Both the front and back feature a sequence of coloured shapes running along the outer edge. These coloured shapes aren't simply decorative — each one represents a letter of the alphabet.

The key to deciphering the code can be found on the sleeve of New Order's second studio album, *Power, Corruption & Lies*.

## The Colour Key

On the back of the *Power, Corruption & Lies* sleeve is a colour wheel that provides the substitution key needed to translate the coloured shapes into letters.

The colour code was designed by Peter Saville, the renowned graphic designer responsible for much of Factory Records' distinctive visual identity. Factory Records was the independent record label that signed New Order.

Saville developed the system to encode three pieces of information on the album artwork:

- The band's name: **NEW ORDER**
- The album title: **POWER, CORRUPTION & LIES**
- The catalogue number: **FACT 75**

This allowed the original album sleeve to communicate all its essential identifying information without displaying conventional text.

On subsequent reissues, the catalogue number was added as ordinary text, but the original colour-coded design remained.

## Decoding the Colours

The program uses the colour wheel from *Power, Corruption & Lies* as a reference key.

By matching each coloured shape on the *Blue Monday* sleeve to its corresponding position on the colour wheel, the program can identify the letter represented by that colour.

The sequence of decoded letters can then be assembled to reveal the message encoded in the sleeve artwork.
