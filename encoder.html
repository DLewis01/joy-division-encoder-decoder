Colour Alphabet Encoder / Decoder

A digital version of the circular colour alphabet. Each letter is represented by the colours found in its radial sector.

1. Encode a string

Colour code

Numbers: 1–9 use the same nine colour sectors as A–I. Switch the decoder to Numbers (1–9) and the clickable palette becomes 1, 2, 3 … 9. In that mode clicking a colour combination inserts the number, not the corresponding letter.

2. Decode by clicking colours

Click a letter's colour-code tile below to append that letter to the decoded message. Click the space tile to insert a space. Use Backspace or Clear to edit the result.



How the code works

The encoder treats each alphabet position as one radial slice of the original diagram. The code for a letter is the combination of the outer-ring colour, middle-ring colour, and the inner six-part colour occupying that slice. This means the visual code preserves the structure of the original wheel rather than reducing each letter to only one colour.
